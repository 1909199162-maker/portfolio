# 作品集样板站（第 ① 步）

苹果官网手感复刻的**第一步**：3 个静态页 + 可点导航，先不管转场。

## 怎么打开

双击 `index.html`。就这样，不需要装任何东西、不需要命令行。

## 文件结构

```
apple-style-site/
├── index.html      首页（英雄区 + 3 张卡片）
├── works.html      作品页（3 行图文）
├── about.html      关于页
└── assets/
    └── style.css   全部样式 + 手感令牌（唯一需要改的文件）
```

## 改哪里（三处旋钮）

| 想改什么 | 改哪里 |
|---|---|
| 文案 | 各 `.html` 里 `<h1>`/`<p>` 的文字 |
| 主色 | `style.css` 顶部 `--accent: #0071e3` |
| 动效快慢 | `style.css` 顶部 `--t-fast / --t-base / --t-slow` |

**改完必须验证**：`F12` → Console 有没有红字；`Ctrl+Shift+M` → 手机视角有没有横向滚动条。

## 手感令牌的来源

全部数值实测自 apple.com.cn/store（2026-10-28）：

- hover 变色 **320ms**、淡入位移 **240ms**、按压 **100ms**
- 缓动曲线全站唯一：`cubic-bezier(0.4, 0, 0.6, 1)`
- 正文 **17px**（不是 16px）

## 下一步（第 ② 步）

`assets/style.css` 文件末尾有一段被 `/* */` 包住的代码，取消注释即开启页面切换过渡：

- 旧页淡出 150ms → 新页淡入 250ms，新页从 +8px 上移
- 用的是跨文档 View Transitions，不支持的浏览器自动降级为直接切换
- 注意：`file://` 协议下部分浏览器不启用跨文档转场，需要起一个本地服务（`python -m http.server`）才能看到

## 已知取舍

- 字体回退到 Windows 的「Segoe UI + 微软雅黑」。苹果的 SF Pro 不能随便商用分发，别直接拷它的字体文件。
- 图片全是占位块，标了真实尺寸，替换时按尺寸裁，排版不会乱。
